Drift Detection + Remediation helps you continuously compare real infrastructure against your IaC definitions, detect unexpected changes, and drive remediation through the same PR-based workflow your team already uses.

<Note>
  Prerequisites:

  - [Set up your OpenTaco account](/ce/getting-started/account-setup)
  - [Set up GitHub App](/ce/getting-started/github-app-setup)
  - A working PR Automation setup with a functional GitHub Actions workflow
</Note>

## Enable drift detection

To activate drift detection, you must enable it at both levels:

1. In settings, toggle **Enable Slack notifications** on (this enables drift detection at the organization level).
2. In the projects page, toggle **Drift** on for each project you want monitored.
